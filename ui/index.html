Strict rewrites the reference into one teaching spelling (Qian Nairong's 《上海话大词典》), and the model has to write it. Fold counts the same word spelled differently as a match (我/吾, 勿/弗); a different or Mandarin word stays an error. Corpus CER is all errors ÷ all characters in the set, so long clips weigh more (the usual way speech-recognition papers report CER). Average clip CER averages each clip's own CER, so every clip counts the same (the README's headline); it runs higher when a model fails on short clips. Test sets are scored separately, never pooled. A model that hasn't covered every clip shows n/N. A gap of a point or two between models is within noise: read the diffs.
