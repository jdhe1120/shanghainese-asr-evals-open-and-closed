## Familiar data

‡ marks familiar data: evidence the set closely resembles the model's training data, but not the clear sign of training on the test clips themselves (rules/flags.toml).

- **CN-MultiDialect-ASR**, Phone conversation: Writes MagicData's own spellings and punctuation (撒 for 啥, 特 for 脱, commas in the same places): 15% of clips match the reference exactly, punctuation included, against 0-2% for every other model. It doesn't copy a known reference typo (巨 for 贵), so it isn't recalling these clips, but it may have trained on text transcribed the way MagicData transcribes.
- **CN-MultiDialect-ASR**, Podcasts & storytelling: By ASLP@NPU, the lab that built WenetSpeech-Wu-Bench (its held-out test set). Its model card lists ~100k hours of unnamed Mandarin-dialect training data, which likely includes the lab's own WenetSpeech-Wu. The lab's four models get 10-19% of clips exactly right, every other model 3% or less.
- **Whisper-medium-Wu**, Podcasts & storytelling: By ASLP@NPU, the lab that built WenetSpeech-Wu-Bench (its held-out test set); trained on WenetSpeech-Wu, likely from the same kinds of sources. The lab's four models get 10-19% of clips exactly right, every other model 3% or less.
- **Conformer-U2pp-Wu**, Podcasts & storytelling: By ASLP@NPU, the lab that built WenetSpeech-Wu-Bench (its held-out test set); trained on WenetSpeech-Wu, likely from the same kinds of sources. The lab's four models get 10-19% of clips exactly right, every other model 3% or less. Its jump from 17.9% on MagicData to 12.3% here is the largest of any model.
- **Step-Audio2-Wu-ASR**, Podcasts & storytelling: By ASLP@NPU, the lab that built WenetSpeech-Wu-Bench (its held-out test set); fine-tuned on WenetSpeech-Wu, likely from the same kinds of sources. The lab's four models get 10-19% of clips exactly right, every other model 3% or less.

## Models

- **Step-Audio2-Wu-ASR**: stepfun-ai/Step-Audio-2-mini (8.3B) + ASLP-lab WenetSpeech-Wu stepaudio2-ASR LoRA, ms-swift 3.9.3 PtEngine, prompt <audio>语音说了什么, greedy, bf16, on Modal A100 40 GB (batched).
- **Conformer-U2pp-Wu**: ASLP-lab/WenetSpeech-Wu-Speech-Understanding u2++/u2++.pt (sha256 9afd6fd8), Conformer U2++ trained from scratch on WenetSpeech-Wu; WeNet a54b90b, default decode, CPU, dither 0.
- **Whisper-medium-Wu**: ASLP-lab/WenetSpeech-Wu-Speech-Understanding whisper/whisper-medium.pt (sha256 e2755246), Whisper medium fine-tuned on WenetSpeech-Wu; WeNet a54b90b, default decode, CPU.
- **CN-MultiDialect-ASR**: ASLP-lab/CN-MultiDialect-ASR: Qwen3-ASR-1.7B + continual pre-training, dialect SFT and on-policy self-distillation (ASLP@NPU, WenetSpeech-Wu authors). qwen-asr 0.0.6 in an isolated env, auto language.
- **Qwen3-ASR-1.7B**: Qwen/Qwen3-ASR-1.7B-hf, untuned. Wu is one of its 22 Chinese dialects; no Wu language name exists, so language is auto-detected.
- **Dolphin-CN-Dialect small**: DataoceanAI Dolphin-CN-Dialect small.cn (0.4 B, May 2026) via dataoceanai-dolphin, lang_sym zh, region_sym SHANGHAI.
- **Fun-ASR-Nano-2512**: FunAudioLLM/Fun-ASR-Nano-2512-hf (Tongyi, Dec 2025), transformers-native, language zh (7 dialect groups incl. Wu; no Wu setting), greedy, float32.
- **Qwen3-Omni-30B-A3B + Shanghainese prompt**: Same weights and setup as the Chinese-prompt row, prompt 请将这段上海话录音逐字转写成上海话口语。 (the Cantonese evals' GLM-ASR Cantonese prompt with the language swapped).
- **Qwen3-Omni-30B-A3B**: Qwen/Qwen3-Omni-30B-A3B-Instruct (30B MoE, 3B active; the model Qwen3-ASR was trained from), audio output off, transformers 5.19, prompt 请将这段中文语音转换为纯文本。 (the model card's Chinese ASR prompt; no language setting exists), greedy, bf16, on Modal A100 80 GB (batched).
- **Azure Speech**: Azure Speech fast transcription, standard recognizer, locale wuu-CN (Chinese, Wu, Simplified), api-version 2025-10-15. Microsoft doesn't name the model.
- **Gemini 4 Argon**: gemini-4-argon via generateContent, audio inline with a prompt asking for verbatim spoken Shanghainese in simplified characters (gemini_argon.PROMPT, the Cantonese evals' prompt with the language swapped), default sampling. Google names no speech languages for it.
